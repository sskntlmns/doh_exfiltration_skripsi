Introduction & Problem Statement

01

DNS-over-HTTPS (DoH — RFC 8484) encrypts DNS queries over standard HTTPS port 443, effectively blending with regular web traffic unlike DoT (port 853), making it exceptionally challenging to isolate without granular flow inspection.

  • Core Dilemma: Conventional IDS relying on Deep Packet Inspection (DPI) fails against encrypted TLS without intrusive SSL/TLS proxy decryption that compromises user confidentiality.
  • Adversary Weaponization: Threat actors exploit DoH via Base64/Hex subdomain encoding for covert data exfiltration and C2 tunneling, bypassing perimeter signature firewalls.
  • Proposed Solution: ML classification leveraging statistical flow metadata (packet length distribution, byte volume, IAT) with zero payload inspection overhead.
Tested Tools: dnscat2 iodine DNSExfiltrator dns2tcp

Threshold Optimization (θ = 0.45)

04

Lowering threshold from 0.50 → 0.45 identifies the optimal operating point on the Precision-Recall curve, boosting Recall to 99.9820% and peak F1-Score to 99.9890%:

  • False Negative Reduction: FN dropped from 11 → 9 instances (capturing 2 additional critical exfiltration flows).
  • Zero FPR Penalty: False positives maintained at only 2 instances out of 48,491 benign samples (TN = 48,489).

Robustness & Adversarial Evasion

07

Transparent Adversarial Vulnerability Assessment: Evaluating model robustness against active traffic evasion attempts targeting dominant flow metadata features.

Adversarial Threat Vectors
• Packet Padding: Mutating PacketLengthMode via dummy bytes.
• Timing Jitter: Obfuscating FlowIAT time-based features.
Defense & Mitigation Strategy
• Multi-Model Ensemble: RF + AdaBoost diversity.
• Adversarial Retraining: Periodic retraining on augmented attack flows.
  • Non-Adversarial Baseline: Model trained on standard flow metadata without adversarial samples, establishing a transparent baseline for future robust ML research.
  • Target Feature Exploitation: Padding attacks attempt to flatten PacketLengthMode (Gini: 0.2251), making malicious traffic statistically mirror variable benign browsing.
  • Robust Optimization Roadmap: Recommends integrating Adversarial Training and continuous Red-Teaming simulations to harden the ML engine before production deployment.

Conclusion & SOC Operational Roadmap

08

Flow metadata machine learning effectively detects encrypted DoH exfiltration without payload decryption, fully preserving end-user privacy while maintaining operational security.

  • Random Forest: Peak performance — accuracy 99.98%, FPR 0.000041, and real-time inference speed (0.0036 ms/sample).
  • Threshold 0.45: Maximizes recall (FN = 9) with minimal false alarm overhead for SOC teams.
  • Alert Deduplication: Recommends technical implementation of 60-second Time-Window Aggregation in log pipelines to consolidate repetitive alerts by Source/Dest IP, preventing analyst fatigue.
  • Future Work: Real-time streaming pipeline integration with Adversarial Training.

Key Takeaway: Non-payload ML is highly viable, cost-effective, and production-ready for enterprise SOC deployment.
